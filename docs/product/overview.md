# Product overview

SkillBridge connects evidence of work to human-reviewed skills and verifiable rewards.

## Participants

- Students maintain a wallet profile, join public or invited challenges and submit files.
- Businesses define a brief, choose the reviewing organization and fund rewards.
- Reviewers can belong to the business itself or an independent business/university.
- Public visitors can inspect shared profiles and credential status within visibility rules.

## Main journey

1. Create a draft with a structured brief, rubric and reward.
2. Fund/configure the appropriate reward path and publish.
3. Student joins and submits evidence; the program escrow path adds signed admission.
4. Reviewer scores manually or requests optional AI assistance.
5. Authorized humans approve the official result.
6. Credentials can be issued; program awards are allocated and claimed separately.

A passing score does not automatically allocate an award. See the
[escrow runbook](../solana/escrow-runbook.md).

## Supporting journeys

Wallet profiles, talent discovery, opportunity verification, milestone contracts,
USDC invoice reconciliation and a Devnet-to-VND sandbox support the main flow.

The on-chain environment is Devnet. VND bank settlement remains sandbox.
